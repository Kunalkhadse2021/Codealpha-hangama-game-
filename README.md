# 🎮 Hangman Game (Python)

A simple word-guessing game where you guess letters to reveal a hidden word before running out of attempts.

## Features
- Random word selection
- 6 wrong guesses allowed
- Shows correct letters and wrong guesses
- Win/Lose message
- Play again option

## Requirements
- Python 3.x

## How to Run
1. Clone the repo: `git clone https://github.com/<your-username>/hangman-game-python.git`
2. Go to the folder: `cd hangman-game-python`
3. Run: `python hangman.py`

## How to Play
1. Guess one letter at a time
2. Each wrong guess uses up an attempt
3. Guess the full word before attempts run out!
